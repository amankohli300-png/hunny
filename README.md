# Hunny Surfaces

A responsive, single-page website concept for a modern surfaces and interiors brand. The visual direction takes inspiration from contemporary decorative-surface manufacturer websites, while using original branding and copy.

## Preview locally

Open `index.html` in a browser. The page uses Google Fonts and remotely hosted Unsplash photography, so an internet connection is needed for those assets.

## Publish with GitHub Pages

1. Open this repository's **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/ (root)**, then click **Save**.
5. Wait for GitHub Pages to publish the site. The expected URL is `https://amankohli300-png.github.io/hunny/`.

## Before launch

Replace the sample email address `hello@hunnysurfaces.example` with a real contact email, and replace placeholder brand/product information and imagery with assets you have permission to use.
